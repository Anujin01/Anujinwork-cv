# Anujin | Cybersecurity & IT Support

A modern personal portfolio website for Anujin, a cybersecurity student seeking an entry-level remote IT support role. The site highlights technical strengths, learning progress, and a clean, professional online presence.

## ✨ Overview

This project is a responsive personal landing page built with HTML, CSS, and JavaScript. It presents:

- cybersecurity and IT support experience
- academic and skill development
- professional contact information
- a polished digital portfolio aesthetic

## 🧩 Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Anujin01/Anujinwork-cv.git
   ```
2. Open the project folder:
   ```bash
   cd Anujinwork-cv
   ```
3. Start a local server or open `index.html` directly in your browser.

Example using Python:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```
